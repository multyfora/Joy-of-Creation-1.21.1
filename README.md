## Remote Control

Fly your ship without standing at the helm.

| Item | What it does |
| :--- | :--- |
| **Portable Typewriter** | A handheld typewriter that lets you control ships from anywhere. Bind any key to a Redstone Link frequency. |
| **Portable Throttle Lever** | Sends an analog redstone signal of any strength wirelessly, as long as you are holding it and nearby. |

---

## Navigation

### Seeker

The Seeker tracks a target and outputs redstone signals pointing toward it, so you can build a working autopilot.

**Target modules**

| Module | Tracks |
| :--- | :--- |
| Spyglass | A set of coordinates |
| Eye of Ender | A player's direction |
| Modulating Receiver | A distance signal |

**Highlights**

- **2D mode** for horizontal steering, or **3D mode** with output on all six sides
- Distance readout, plus linking of multiple Seekers together
- Waypoint picker with **Xaero's World Map** support

## Flight

| Block | What it does |
| :--- | :--- |
| **Balloons** | Lift blocks in all 16 colors. Inflate a deflated balloon by holding use on it. Lift and drag are fully configurable. |
| **Symmetric Cross Sails** | Sails in all 16 colors that provide planar drag. |
| **Gyroscopic Seat** | Keeps the rider's view steady while the ship rotates around them. |

## Sub-level Tools

| Tool | What it does |
| :--- | :--- |
| **Shatter Assembler** | Splits a connected solid structure into separate sub-levels. |
| **Shears** | Cuts a sub-level cleanly in two. |
| **Creative Staff** | Grab and move entities. Moving other players can be enabled in the config. |
